### 四、你要做的事（按优先级，做完一项验一项）

**任务 1（最高优先）：查清 `personality_traits` 为什么从 0.60 掉到 0.25。**

拿 `runs/eval-smoke-official/submission.jsonl` 和 `runs/eval-smoke-wired/submission.jsonl` 逐条 diff，看你的提示词到底把输出改成了什么样。重点怀疑：

- 提示词是否让模型输出了**训练时没见过的标签词**（真值是有限标签集，见 `configs/label_space.json`）
- 是否让模型把三维画像的**输出格式**改了（比如加了解释文字、换了分隔符）
- 是否把某一维挤掉了（三维要同时给，缺一维就按错算）

**任务 2：修 `micro-F1 = 0` 但 `Jaccard = 0.55–0.60` 的矛盾。**

这个矛盾很说明问题：**集合精确匹配挂零，宽松匹配过半**。意思是——**模型其实猜对了大半，只是写的词和真值的词对不上。**

去 `configs/label_space.json` 读真值用的标签表，让你的提示词**必须从这张表里选词**，不要自由发挥同义词。这是**白捡的分**，先把这块吃掉再谈别的。

**任务 3：保住 `style` 那条唯一的正收益。**

`style` 从 0.20 涨到 0.30，说明你的提示词在风格方向写对了。**回退提示词时不要连它一起删掉。**

**任务 4：用满 GPU。**

你现在的迭代循环是 3.5 分钟一轮。**一次只改一个变量，跑一轮，看台账，再改下一处。** 别攒十个改动一起跑——那样你分不清是哪个改对的。
